Словарь специальности

Алгоритм
Последовательность действий для решения определённой задачи.
Программа
Набор команд, которые компьютер выполняет для получения результата.
Переменная
Область памяти, в которой хранится значение, используемое программой.
Функция
Отдельный блок программы, выполняющий определённую задачу.
HTML
Язык разметки, который используется для создания структуры веб-страниц.
